# DIS
Dust Injection Simulator (DIS) code for computing the trajectory of powder grains into 3D time dependent background plasmas

DIS is a standalone Matlab package. The main routine is DIS.m. To run locally, change test=1 in the DIS.m routine. test=0 is used to run DIS in series of jobs.

The simulation parameters and input files, path to running directory, are set in the input_DIS.txt file.

Example routines to create a plasma background from EMC3-EIRENE simulation outputs are provided.
